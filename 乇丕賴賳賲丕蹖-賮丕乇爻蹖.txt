اپ گزارش تماس شمسی - راهنمای ساخت APK فقط با گوشی

۱) فایل ZIP پروژه را در گوشی دانلود و از حالت فشرده خارج نکنید؛ GitHub می‌تواند ZIP را به عنوان فایل مخزن نگه دارد، اما برای اجرای ساخت خودکار باید فایل‌ها داخل مخزن باشند.

۲) در مرورگر گوشی وارد https://github.com شوید و یک حساب بسازید یا وارد شوید.
۳) از علامت +، گزینه New repository را بزنید؛ نام مخزن را PersianCallLog بگذارید و آن را Public یا Private ایجاد کنید.
۴) برای بارگذاری فایل‌ها، از صفحه مخزن گزینه Add file > Upload files را بزنید. ابتدا باید محتویات پوشه پروژه را بارگذاری کنید (نه اینکه فقط ZIP را بارگذاری کنید). پوشه مخفی .github را هم بارگذاری کنید؛ اگر رابط موبایل اجازه بارگذاری پوشه مخفی را نداد، فایل .github/workflows/build-apk.yml را از طریق Add file > Create new file با همین مسیر بسازید.
۵) پس از ثبت فایل‌ها در شاخه main، صفحه مخزن > Actions را باز کنید. گردش‌کار «Build Android APK» باید اجرا شود. اگر اجرا نشد، آن را انتخاب و Run workflow را بزنید.
۶) وقتی اجرا سبز و موفق شد، همان صفحه اجرای workflow را باز کنید. در بخش Artifacts روی PersianCallLog-debug-apk بزنید تا APK را به صورت ZIP دانلود کنید.
۷) ZIP آرتیفکت را در گوشی استخراج کنید و app-debug.apk را نصب کنید. ممکن است لازم باشد برای مرورگر/مدیر فایل اجازه «نصب برنامه‌های ناشناس» را فعال کنید.

نکته: GitHub Actions برای مخازن عمومی معمولاً قابل استفاده است؛ برای مخازن خصوصی، سهمیه و محدودیت‌های حساب GitHub اعمال می‌شود. اجرای اولین ساخت به اینترنت نیاز دارد. این پروژه و workflow هنوز روی دستگاه واقعی آزمایش نشده‌اند. APK خروجی نسخه debug است و برای نصب شخصی است.
